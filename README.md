# OP1
Ocean Practices Maturity Levels

Levels defining the maturity of an ocean practice. The levels and their defining criteria are used to assess the maturity of the ocean practices documentation. Assessment does not address the maturity of the underlying science or technology.

## Request for new terms and ways to contribute
- Requests for a new OP1 can be submitted as [regular issues](https://github.com/nvs-vocabs/OP1/issues) in this repository or emailed to vocab.services-at-bodc.ac.uk.

- Reporting errors or suggestions for improving content can be also be submitted as above.
